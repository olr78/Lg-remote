# LG Remote — пульт для LG UF950V (webOS 3.0)

Android-застосунок, що керує телевізором по Wi-Fi через протокол LG webOS SSAP
(WebSocket, порт 3000) — той самий, що використовує офіційний LG TV Plus.

## Що вміє
- Автопошук ТВ у мережі (SSDP) або ручний IP
- Парування один раз (підтвердити на ТВ), ключ зберігається
- D-pad, OK, Назад, Home, Меню, Exit, Info, цифри, кольорові кнопки
- Гучність (+ апаратні кнопки гучності телефону), Mute, канали
- Play / Pause / Stop / ⏪ / ⏩
- Тачпад як курсор Magic Remote (тап = клік, два пальці = прокрутка)
- Введення тексту в поля на ТВ (пошук YouTube тощо)
- Список входів (HDMI 1–4…) і застосунків для запуску
- Вимкнення ТВ та увімкнення через Wake-on-LAN

## Збірка
**Варіант A — Android Studio:** File → Open → папка `LgRemote`, дочекатись Gradle sync,
Run (або Build → Build APK(s)).

**Варіант B — без Android Studio:** залити папку в репозиторій GitHub — workflow
`.github/workflows/build.yml` сам збере APK; забрати в Actions → останній запуск → Artifacts.

## Налаштування ТВ
1. Телефон і ТВ — в одній мережі.
2. Перше підключення: на ТВ з'явиться запит — натиснути «Так/Дозволити».
3. Для увімкнення з телефону:
   - Налаштування → Загальні → **Mobile TV On / Увімкнення через мобільний** → Увімк.
   - MAC взяти в Налаштування → Загальні → Про цей ТВ (бажано MAC того інтерфейсу,
     яким підключений ТВ; по кабелю WOL надійніший, ніж по Wi-Fi).
4. Варто закріпити за ТВ статичний IP у DHCP роутера.

## Примітки
- UF950V — webOS 3.0, тому використовується `ws://` без TLS. Для webOS 4.5+
  потрібно міняти на `wss://<ip>:3001` (у `LgTvClient.connect()`).
- Якщо після скидання ТВ підключення відхиляється — застосунок сам перепарується.
